## ✨ Features

- 🌓 **Dynamic Light & Dark Theme:** Full system support with quick toggle button and persistent user preference in `localStorage`.
- 🎨 **Modern Picto Aesthetic:** Clean floating cards, rounded corners, fluid ambient mesh glow, and elegant typography.
- 📱 **Fully Responsive:** Seamlessly optimized for desktops, tablets, and mobile devices with a custom slide drawer menu.
- 💼 **Professional Experience Timeline:** Interactive showcase of roles and achievements at Nebula Technology (Super Admin Module for School ERP).
- 🛠️ **Categorized Skills Arsenal:** Filterable technology groups (Frontend, Java Core, Backend, Dev Concepts, Tools).
- 🚀 **Projects Showcase:** Real enterprise production applications and full stack capstone projects.
- 📄 **Interactive Resume Modal:** In-browser resume viewer with one-click "Print / Save PDF" support.
- 📬 **Validated Contact Form:** Form validation powered by `react-hook-form` and direct copy-to-clipboard contact channels.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Patil-Vaishnavi97/react-portfolio.git
cd react-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
